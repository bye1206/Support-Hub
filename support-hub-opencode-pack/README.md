# Support Hub — пакет контекста для OpenCode

Этот каталог передаёт coding-agent контекст проекта Support Hub и правила дальнейшей работы.

## С чего начать

1. Распакуйте архив в корень нового Git-репозитория (или скопируйте содержимое в уже созданный репозиторий, предварительно сохранив существующие файлы).
2. Откройте терминал в корне проекта.
3. Запустите OpenCode: `opencode`.
4. Вставьте содержимое [`PROMPT_START_RU.md`](PROMPT_START_RU.md) в чат OpenCode.
5. На первом шаге попросите агента провести аудит репозитория и подготовить план технического старта. Не разрешайте ему сразу генерировать весь продукт целиком.

## Что находится в пакете

- `AGENTS.md` — постоянные правила проекта, которые OpenCode должен автоматически читать.
- `PROMPT_START_RU.md` — стартовый запрос для первого сеанса.
- `docs/` — проектный контекст: продукт, правила, архитектура, данные, интеграции, интерфейсы, безопасность и план.
- `.env.example` — перечень будущих переменных окружения без реальных секретов.

## Важная оговорка о зрелости проекта

Это **проектный handoff-пакет**, составленный по результатам обсуждения требований. Он не является готовым исходным кодом, полностью проверенным DDL или утверждённым OpenAPI-файлом.

Ранее подготовленные в обсуждении SQL и JSON-примеры были проектными эскизами. Не переносить их механически в production-код. OpenCode должен сначала проверить целостность решений, отметить противоречия и сформировать канонические спецификации.

## Принцип работы с решениями

Приоритет имеют:

1. Явно подтверждённые пользователем решения из `docs/12_DECISION_LOG.md`.
2. Открытые вопросы из `docs/11_OPEN_QUESTIONS.md` — их нельзя выдавать за решённые.
3. Проектные предложения и примеры API — только как основа для проверки и согласования.

Если вопрос критичен для архитектуры или безопасности, агент должен остановиться и запросить решение пользователя. Если вопрос не блокирует текущую задачу, он должен записать допущение и продолжить ограниченную работу.

## Официальные инструкции OpenCode

OpenCode поддерживает проектный `AGENTS.md` для постоянных инструкций. Его следует хранить и коммитить в корне репозитория. См. официальную документацию: https://opencode.ai/docs/instructions/ .
